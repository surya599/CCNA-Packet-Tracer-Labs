# IPv6 SLAAC and Static Routing with Backup Path

## Objective

Configure IPv6 routing across three routers using:

* IPv6 unicast routing
* SLAAC for PC addressing
* Static routes
* A direct R1–R3 path as the primary route
* R1–R2–R3 as the backup path
* Link-local addresses on the serial connections

## Topology

* **R1 LAN:** `2001:db8:0:1::/64`
* **R3 LAN:** `2001:db8:0:3::/64`
* **R1–R3:** `2001:db8:0:13::/64`

  * R1 G0/1: `2001:db8:0:13::1/64`
  * R3 G0/1: `2001:db8:0:13::2/64`
* **R1–R2:** Serial, link-local only
* **R2–R3:** Serial, link-local only

## 1. Enable IPv6 Routing

### R1

```cisco
R1> enable
R1# configure terminal
R1(config)# ipv6 unicast-routing
R1(config)# end
```

### R2

```cisco
R2> enable
R2# configure terminal
R2(config)# ipv6 unicast-routing
R2(config)# end
```

### R3

```cisco
R3> enable
R3# configure terminal
R3(config)# ipv6 unicast-routing
R3(config)# end
```

## 2. Configure SLAAC on the PCs

The router advertisements generated by the IPv6-enabled LAN interfaces allow the PCs to automatically configure their IPv6 addresses using SLAAC.

### PC1

Go to:

`PC1 > Desktop > IP Configuration > IPv6 Configuration`

Select:

```text
Auto Config
```

PC1 should receive an address from:

```text
2001:db8:0:1::/64
```

### PC2

Go to:

`PC2 > Desktop > IP Configuration > IPv6 Configuration`

Select:

```text
Auto Config
```

PC2 should receive an address from:

```text
2001:db8:0:3::/64
```

Verify the addresses using:

```text
ipconfig
```

## 4. Configure the Primary Static Route on R1

R1 needs a route to the R3 LAN:

```cisco
R1(config)# ipv6 route 2001:db8:0:3::/64 2001:db8:0:13::2
```

This uses the direct R1–R3 connection as the primary path.

Verify:

```cisco
R1# show ipv6 route
```

You should see a static route similar to:

```text
S   2001:DB8:0:3::/64 [1/0]
     via 2001:DB8:0:13::2
```

## 5. Configure the Primary Static Route on R3

R3 needs a route to the R1 LAN:

```cisco
R3(config)# ipv6 route 2001:db8:0:1::/64 2001:db8:0:13::1
```

Verify:

```cisco
R3# show ipv6 route
```

## 6. Configure Routes on R2

R2 must know how to reach both LAN networks.

Because the serial links use **link-local addresses only**, specify both the outgoing interface and the neighbor's link-local address.

### R2 → R1 LAN

```cisco
R2(config)# ipv6 route 2001:db8:0:1::/64 s0/0/0 <R1-link-local-address>
```

### R2 → R3 LAN

```cisco
R2(config)# ipv6 route 2001:db8:0:3::/64 s0/0/1 <R3-link-local-address>
```

Replace the placeholders with the actual link-local addresses shown by:

```cisco
show ipv6 interface s0/0/0
show ipv6 interface s0/0/1
```

## 7. Configure R1 Backup Route Through R2

The direct R1–R3 route should be preferred. The route through R2 should therefore have a higher administrative distance.

```cisco
R1(config)# ipv6 route 2001:db8:0:3::/64 s0/0/0 <R2-link-local-address> 200
```

Here:

```text
200 = Administrative Distance
```

The primary route has the default AD of `1`, while the backup route has AD `200`.

Therefore:

```text
Primary: R1 → R3
Backup:  R1 → R2 → R3
```

## 8. Configure R3 Backup Route Through R2

Configure the reverse backup path:

```cisco
R3(config)# ipv6 route 2001:db8:0:1::/64 s0/0/0 <R2-link-local-address> 200
```

This creates:

```text
Primary: R3 → R1
Backup:  R3 → R2 → R1
```

## 9. Verify the Routing Tables

On R1:

```cisco
show ipv6 route
```

On R2:

```cisco
show ipv6 route
```

On R3:

```cisco
show ipv6 route
```

Look for:

```text
S = Static
C = Connected
L = Local
```

The primary static routes should have:

```text
[1/0]
```

The floating backup routes should have:

```text
[200/0]
```

## 10. Test Connectivity

From PC1, ping PC2:

```text
ping <PC2-IPv6-address>
```

From PC2, ping PC1:

```text
ping <PC1-IPv6-address>
```

Both PCs should successfully communicate.

## 11. Test the Backup Path

To verify that the backup route works, temporarily shut down the direct R1–R3 interface:

### R1

```cisco
R1(config)# interface g0/1
R1(config-if)# shutdown
```

The direct route should disappear, causing traffic to use:

```text
PC1 → R1 → R2 → R3 → PC2
```

Test again from PC1:

```text
ping <PC2-IPv6-address>
```

After testing, restore the interface:

```cisco
R1(config)# interface g0/1
R1(config-if)# no shutdown
```

## Key Concepts Learned

* IPv6 unicast routing must be enabled using `ipv6 unicast-routing`.
* SLAAC allows hosts to automatically configure IPv6 addresses from router advertisements.
* IPv6 routers can use global unicast addresses for static routes.
* IPv6 static routes using link-local next-hop addresses require the outgoing interface to be specified.
* Administrative distance can be used to create a **floating static route**.
* A floating static route provides redundancy when the primary route fails.
* The topology uses R1–R3 as the primary path and R1–R2–R3 as the backup path.

## Expected Traffic Flow

### Normal Operation

```text
PC1 → R1 → R3 → PC2
```

### When the Direct R1–R3 Path Fails

```text
PC1 → R1 → R2 → R3 → PC2
```
