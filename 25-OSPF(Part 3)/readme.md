# OSPF Area 0 Troubleshooting Lab

## Overview

This lab focuses on configuring and troubleshooting **OSPF Area 0** in a multi-router network.

## Objectives

- Configure the newly added R1–R2 serial connection
- Configure OSPF on R1 and R2
- Troubleshoot missing OSPF routes
- Fix OSPF neighbor adjacency issues
- Configure default route propagation
- Provide connectivity to the external server `8.8.8.8`
- Examine the OSPF Link-State Database (LSDB)
- Identify different OSPF LSAs

## Tasks

### 1. Configure R1–R2 Serial Connection

Configure the `192.168.12.0/30` serial link between R1 and R2.

- R1: `192.168.12.1`
- R2: `192.168.12.2`
- Clock rate: `128000`

Verify the connection:

```cisco
show ip interface brief
ping 192.168.12.2
```

### 2. Configure OSPF on R1 and R2

Configure both routers in **OSPF Area 0** and advertise the required networks.

Verify the adjacency:

```cisco
show ip ospf neighbor
```

### 3. Troubleshoot the 10.0.2.0/24 Route

Only R3 initially has a route to `10.0.2.0/24`.

Check the OSPF configuration on R3 and ensure the network is being advertised into Area 0.

```cisco
show running-config | section router ospf
show ip route ospf
```

### 4. Fix OSPF Neighbor Adjacencies

R2 and R4 are unable to establish OSPF neighbor relationships with R5.

Check:

```cisco
show ip ospf neighbor
show running-config | section router ospf
show ip interface brief
```

Ensure the correct interfaces are participating in OSPF and are not incorrectly configured as passive interfaces.

### 5. Provide External Connectivity

Configure a default route on R5 toward ISP1:

```cisco
ip route 0.0.0.0 0.0.0.0 203.0.113.2
```

Advertise the default route into OSPF:

```cisco
router ospf 1
default-information originate
```

Verify that the internal routers learn the default route:

```cisco
show ip route
```

The route should appear as:

```text
O*E2 0.0.0.0/0
```

Test connectivity:

```text
PC1 > ping 8.8.8.8
PC2 > ping 8.8.8.8
```

### 6. Examine the OSPF LSDB

Use:

```cisco
show ip ospf database
show ip ospf database router
show ip ospf database network
show ip ospf database summary
show ip ospf database external
```

## Important OSPF LSAs

| LSA | Name | Purpose |
|---|---|---|
| Type 1 | Router LSA | Describes router links within an area |
| Type 2 | Network LSA | Generated by the DR on multi-access networks |
| Type 3 | Summary LSA | Advertises networks between areas |
| Type 4 | ASBR Summary LSA | Provides reachability to an ASBR |
| Type 5 | External LSA | Advertises external routes |
| Type 7 | NSSA External | Used for external routes in an NSSA |
