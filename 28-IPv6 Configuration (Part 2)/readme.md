# Day 32 – IPv6 EUI-64, IPv6 Enable & Static Routing

## 📌 Lab Overview

Today’s lab focused on configuring IPv6 using **EUI-64**, assigning IPv6 addresses to end devices, enabling IPv6 on router interfaces without manually assigning a global IPv6 address, and configuring basic IPv6 static routes.

### Objectives

* Configure IPv6 addresses using **EUI-64**
* Calculate and understand the EUI-64 Interface ID
* Configure IPv6 addresses and default gateways on PCs
* Enable IPv6 forwarding on the routers
* Enable IPv6 on an interface without explicitly configuring an IPv6 address
* Configure IPv6 static routes
* Verify end-to-end IPv6 connectivity

---

## 🗺️ Addressing Scheme

| Device | Interface | IPv6 Network        | IPv6 Address         |
| ------ | --------- | ------------------- | -------------------- |
| PC1    | NIC       | `2001:db8::/64`     | `2001:db8::2/64`     |
| R1     | G0/1      | `2001:db8::/64`     | EUI-64               |
| R1     | G0/0      | IPv6 transit link   | Link-local           |
| R2     | G0/0      | IPv6 transit link   | Link-local           |
| R2     | G0/1      | `2001:db8:0:1::/64` | EUI-64               |
| PC2    | NIC       | `2001:db8:0:1::/64` | `2001:db8:0:1::2/64` |

## 🔹 Step 1 – Enable IPv6 Routing

### R1

```bash
enable
configure terminal
ipv6 unicast-routing
```

### R2

```bash
enable
configure terminal
ipv6 unicast-routing
```

---

## 🔹 Step 2 – Configure EUI-64 on R1 G0/1

R1's G0/1 belongs to the `2001:db8::/64` network.

```bash
interface g0/1
ipv6 address 2001:db8::/64 eui-64
no shutdown
exit
```

Verify:

```bash
show ipv6 interface g0/1
```

The router automatically generates the interface ID from the interface MAC address using the **EUI-64** process.

---

## 🔹 Step 3 – Configure EUI-64 on R2 G0/1

R2's G0/1 belongs to the `2001:db8:0:1::/64` network.

```bash
interface g0/1
ipv6 address 2001:db8:0:1::/64 eui-64
no shutdown
exit
```

Verify:

```bash
show ipv6 interface g0/1
```

---

## 🔹 Step 4 – Enable IPv6 on the R1–R2 Link

The G0/0 interfaces do not receive an explicitly configured global IPv6 address.

Instead, IPv6 is enabled so that the interfaces can automatically generate a **link-local IPv6 address**.

### R1

```bash
interface g0/0
ipv6 enable
no shutdown
exit
```

### R2

```bash
interface g0/0
ipv6 enable
no shutdown
exit
```

Verify the link-local addresses:

```bash
show ipv6 interface brief
```

---

## 🔹 Step 5 – Configure PC1

Configure PC1 with:

```text
IPv6 Address:     2001:db8::2
Prefix Length:    64
Default Gateway:  R1 G0/1 IPv6 address
```

The default gateway should be the IPv6 address generated by EUI-64 on R1 G0/1.

---

## 🔹 Step 6 – Configure PC2

Configure PC2 with:

```text
IPv6 Address:     2001:db8:0:1::2
Prefix Length:    64
Default Gateway:  R2 G0/1 IPv6 address
```

## 🔹 Step 7 – Check IPv6 Addresses

### R1

```bash
show ipv6 interface brief
```

### R2

```bash
show ipv6 interface brief
```

Also check the complete IPv6 interface information:

```bash
show ipv6 interface g0/1
```

This allows you to see the EUI-64 generated IPv6 address and link-local address.

---

## 🔹 Step 8 – Configure IPv6 Static Routes

R1 needs a route to the PC2 network:

```text
2001:db8:0:1::/64
```

### R1

```bash
ipv6 route 2001:db8:0:1::/64 g0/0
```

R2 needs a route to the PC1 network:

```text
2001:db8::/64
```

### R2

```bash
ipv6 route 2001:db8::/64 g0/0
```

Verify the routing tables:

```bash
show ipv6 route
```

You should see the static routes marked with:

```text
S
```

## 🔹 Step 9 – Test Connectivity

From PC1:

```bash
ping 2001:db8:0:1::2
```

From PC2:

```bash
ping 2001:db8::2
```

Successful replies confirm that IPv6 routing is working between the two LANs.

## 🧠 EUI-64 Concept

EUI-64 allows a router to automatically generate the **64-bit interface ID** of an IPv6 address from the interface MAC address.

The basic process is:

```text
48-bit MAC Address
        ↓
Split into two 24-bit halves
        ↓
Insert FFFE in the middle
        ↓
Invert the Universal/Local (U/L) bit
        ↓
64-bit Interface ID
```

For example, a MAC address such as:

```text
00AA.BBCC.DDEE
```

is transformed into an EUI-64 interface ID.

The resulting IPv6 address becomes:

```text
Network Prefix + EUI-64 Interface ID
```

## 📝 Key Takeaways

* **EUI-64** automatically generates the 64-bit IPv6 interface ID from a MAC address.
* `ipv6 unicast-routing` enables IPv6 packet forwarding on a Cisco router.
* `ipv6 enable` enables IPv6 processing and automatically creates a link-local address without configuring a global IPv6 address.
* IPv6 routers can use **link-local addresses** for communication on directly connected links.
* IPv6 static routes are configured using the `ipv6 route` command.
* IPv6 routing tables can be verified with `show ipv6 route`.
* The `S` code in the IPv6 routing table represents a **static route**.
